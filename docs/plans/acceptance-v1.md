## Blocking scenarios

- **AS-01 / R1, input contract:** mapped CSVs preserve string IDs/leading zeros, optional description mapping, missing and blank distinctions, duplicates/source rows, configured year despite conflicting dates in text, deterministic record IDs, config-relative paths from another working directory, and immutable source hashes. Missing required columns/invalid mapping fail actionably without silent repair.
- **AS-02 / R2, English eligibility:** clear English/non-English, mixed, ambiguous short and unusable text stay accounted for. Test below/at/above threshold and minimum evidence, plus a sensitivity threshold. Fixed documented rules; export confidence/reasons and reconciled annual coverage. Offline detector smoke test. No automatic resource download or assertion that language confidence is domain-validated.
- **AS-03 / R3, linguistic metrics:** independently count title/description/combined text, bullets, missing descriptions, fragments and OOV words. Test standard Flesch formulas and declared segmentation/syllable rules. Short-text flags, metric-specific coverage, no zero imputation/fabrication/network resources/readability-as-quality claim.
- **AS-04 / R4, rubric mathematics:** valid point mass/uniform/nonuniform probabilities and explicit NA; reject missing/unknown options, negative/nonfinite probabilities and invalid sums. Full keyed distributions and four distinct criteria. On conditional assessable probabilities, point mass at 0 gives expectation/entropy 0; uniform gives 1.5/1. NA/abstention means missing under the fixed policy. No middle-score substitution, total index or unsupported feasibility scoring. Packaged anchored/versioned rubric.
- **AS-05 / R5, local backend boundary:** loopback HTTP protocol fixture captures the actual SystemOne question/response shapes. Test valid/malformed/wrong-model/error responses, non-loopback endpoints and external redirects, and demo without explicit synthetic declaration. Enforce local transport and declared model identity; no remote transmission, fallback, or generated prose masquerading as probability extraction. A fixture proves protocol only.
- **AS-06 / R7, weighting/denominators:** assert the literal arithmetic fixture's annual constants and counts above in both in-memory and exported summaries. Employee means precede equal-employee annual means. No goal pooling, zero-filled missingness, or shared denominator across different metrics.
- **AS-07 / R7, pairing:** assert the literal metric-specific paired IDs/changes and common-three-year fixture above. Report actual valid sample counts. No matching individual goals or inferring employee departure from export absence. Test missing values in the all-three-year cohort under the chosen completeness rule.
- **AS-08 / R6, cache/resume:** identical text across employees/years and duplicate source rows share successful scores while retaining all observations/weights. Interrupt after a committed batch and resume without duplicated exports. Independently changing text/rubric/backend/model revision/inference settings invalidates cache. Failed calls stay retryable, never successful-cache entries. Verify call counts and row IDs.
- **AS-09 / R6/R9, failed current runs:** after a successful run reuse its output location with bad config, unavailable backend, malformed output, and simulated write/inference interruption. Status becomes failed/incomplete, affected counts visible; prior success must not appear current. Recovery regenerates consistent artifacts. Check exit codes, manifest and stale report suppression; never hidden zero scoring or failure-as-success.
- **AS-10 / R7/R8, exports/report:** read back CSV/Parquet and reconcile source/aggregate counts and values. Render HTML offline desktop/narrow with empty metric/cohort and HTML-like configured content. Synthetic/unvalidated notices precede findings; chronological contrasts, denominators, missing states, fixed 0-3 score domains, zero-based count axes, coverage and specified sensitivities are visible. Inline charts, accessible tables, escaped content, no external assets or mismatched data. No causal/significance claims or recommendations presented as established effects.
- **AS-11 / R4/R8/R9/R10, privacy/blinding:** distinctive employee/text sentinels and error-provoking text do not reach logs or default report. Captured model requests do not change when employee/year metadata changes for the same text; exclude rollout metadata and preserve legitimate dates inside text. Goals are evidence, not override instructions. Private outputs/cache outside public contents. Verify exact staged files rather than trusting gitignore alone.
- **AS-12 / R1/R9/R10, runnable operations:** actual clean install, both CLI entry points, deterministic same-seed sample hashes, documented quickstart, resume and benchmark. Packaged resources work outside checkout. Manifest records fingerprints/config/model/runtime/code/rubric versions/seeds/counts/failures/status. Windows/Linux setup and offline/real-data transitions documented; synthetic CI configured. No undocumented downloads, demo speed called Clef speed, or unmeasured scale claim.
- **AS-13 / R10, publication:** before publication audit exact staged paths/content for intended code/docs/explicitly synthetic examples/reports only; exclude real data/results/credentials/cache/weights. After required review passes, parent publishes and verifies public visibility/default branch/exact commit and downloaded or cloned contents. Completion depends on this evidence; this does not permit publication before review.
