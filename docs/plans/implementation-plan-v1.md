## Requirements and components

- R1: Python 3.10+ installable package and CLI (`goal-eval` / `python -m goal_eval`) with configuration, separate CSV inputs for 2023/2024/2025, string employee IDs, missing descriptions, explicit file/year and column mappings. Config paths resolve relative to the config file. Synthetic records include repeat employees, changing observation sets, non-English and ambiguous short text, missing descriptions, repeated goals, and performance/development goals. A deterministic sample-data generator must reproduce them.
- R2: Local English language detection with bundled offline model (langid is a suitable small dependency), fixed thresholds/minimum evidence, exported confidence and exclusion reasons. No automatic runtime downloads. Configurable English-threshold sensitivity and coverage by year. Do not treat language scores as validated probabilities for these goals.
- R3: Consistent title, description and combined-text measurements; length/structure statistics and standard Flesch formulas. Use an offline syllable dictionary with documented OOV fallback; flag short/fragmentary readability and report its coverage. No online NLTK downloads. Missing is never zero.
- R4: A versioned anchored 0-3 rubric for clarity, specificity, assessability, coherence, plus descriptive timing/strategy flags. Full categorical probabilities, expectations, normalized entropy, and distinct not-assessable status. No total quality score. All model input excludes employee IDs/year labels/rollout information. Preserve meaningful dates embedded in text. Never infer feasibility or difficulty from text alone.
- R5: Real local decision inference: a loopback-only SystemOne HTTP backend compatible with Clef, and/or direct local release loading following the official model card, with local-only model files and pinned model identity. No silent demo fallback. Explicit real-data configuration defaults to a real backend; demo scoring must require a synthetic declaration and be prominent in artifacts. Retain backend/model/rubric identity in outputs. Test protocol and error paths; disclose that running a stub is not real Clef execution if weights are unavailable.
- R6: Durable SQLite cache keyed by text, rubric, backend, model revision and inference settings; commits in bounded batches; no successful-cache entries for failed inference. Restart reuses successes, retries failures and regenerates outputs without duplicating records. Preserve repeated source records even when sharing scores. Input fingerprint and row-number-derived record IDs make provenance reproducible. Keep source files immutable; atomic/run-scoped outputs prevent stale-success reporting.
- R7: Employee-year means then equal-employee annual means, with per-metric valid counts. Primary 2025-2024, historical 2024-2023, paired 2024/2025 and common-three-year comparisons. No matching individual goals. Preserve metric-specific paired eligibility, missingness/abstention/English/readability coverage. No causal estimates, causal p-values or invented intervals. Goal-level distributions and length-band/title-only sensitivities are descriptive.
- R8: CSV and Parquet scored exports, employee-year summaries, annual/paired/coverage tables, self-contained HTML with inline charts and accessible tables. Synthetic and model-unvalidated notices appear before findings. Chart choices: aligned dots for annual 0-3 scores rather than magnitude bars; zero-based bars/histograms for counts/distributions; small multiples for measures with different units. Fixed score domains, chronological years, visible denominators and missing states. No external scripts/fonts/CDN and no raw text/IDs in the HTML by default. Escape all inserted content. Recommendations link observed rubric weaknesses to possible agent changes and remain hypotheses.
- R9: Manifest with input fingerprints, configuration/rubric/model/runtime/code versions, seeds, coverage/failures, run status and limitations. Privacy-safe console messages. Failures set an explicit failed/incomplete state; a reused directory must not leave a prior success report current. Pilot/benchmark CLI with memory/throughput and extrapolation clearly labeled. Support batching and document memory limits without claiming million-row scalability was tested.
- R10: README with Windows/Linux setup, exact synthetic quickstart and real-data transition, offline dependencies/model instructions, real Clef CPU/GPU limitations, methods/data dictionary, license, synthetic-only CI, technical tests. Public code excludes local environment/caches/model/data/results by default. Check the exact Git index before initial publication.
